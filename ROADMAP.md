# Roadmap

ServicePilot AI is a portfolio MVP focused on local service-business workflow.

## Near term

- Add a short demo recording to the README.
- Improve contributor documentation.
- Add more tests around export and workflow behavior.
- Improve mobile layout for dashboard and forms.
- Document future login and workspace support.

## Medium term

- Add an optional PostgreSQL setup path.
- Add change-history notes for important records.
- Improve CSV export coverage.
- Add clearer seed data reset commands.
- Add more empty-state UI polish.

## Later

- User accounts and workspace ownership.
- Team roles.
- Production database deployment.
- More reporting views.
- Better import/export tools.

## Project principles

- Keep the app easy to run locally.
- Keep tests and docs close to the code.
- Keep demo behavior reliable without required external services.
- Be honest about what is production-ready and what is still prototype work.
