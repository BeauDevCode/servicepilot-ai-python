# Public Launch

ServicePilot AI is public and open to contributors.

## Main message

ServicePilot AI is a FastAPI workflow app for turning messy service-business requests into organized customers, jobs, quotes, invoices, and follow-up tasks.

The project is useful for people who want to practice:

- FastAPI
- SQLModel
- Jinja2
- HTMX-ready forms
- pytest
- Docker
- GitHub Actions
- product workflow design

## How people can follow the project

People can support the project by:

- starring the repository
- watching the repository for updates
- opening issues for bugs or improvements
- picking small roadmap tasks
- submitting focused pull requests

## Good starter areas

- documentation improvements
- screenshot updates
- mobile layout polish
- export tests
- demo data cleanup
- empty-state polish
- setup notes

## Safety rules

Contributors should not commit secrets, `.env` files, local database files, real customer records, private logs, or screenshots with private information.
